# Archived packages / 历史安装包

Superseded release packages are kept here for reference. For installation, use the latest package linked from the [repository README](../README.md).

此目录保存已被新版替代的历史安装包。安装时请使用[仓库首页](../README.md)中链接的最新版本。

On November 12, 2026, these archives were repackaged to remove the root-level `package.xml`, which would otherwise be deployed outside the permitted installation directories. The script files and their signatures were retained. These are corrected archives, not byte-identical copies of the original downloads.
